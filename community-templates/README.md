# Community app templates (staging)

Files here are staged for the ESA-APEx/apex_geospatial_explorer_configs repository
(`config-builder/apps/...`). Copy each folder there and add it to `config-builder/manifest.json`
under `appTemplates`. The Config Builder's tests check that `apps/s2-monitor` builds the same
config as the built-in Satellite STAC Monitor. See docs/reference/app-templates.md.
