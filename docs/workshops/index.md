# Workshops

Workshops are hands-on, follow-along sessions for use in live events. Each workshop
is a series of short exercises that build a real configuration step by step.

Delegates use the **Previous** and **Next** arrows at the bottom of each page to
work through the exercises in order. The left-hand navigation shows the full
outline so you can jump around if needed.

## Available workshops

- [Getting Started](getting-started/index.md) — Build a Geospatial Explorer
  configuration from scratch, covering base maps, direct COG data, WMS services,
  the Project Results Repository (PRR), categories, time series and constraints.

## Running a workshop

Delegates will typically:

1. Open the [Config Builder](https://apex-ge-config-builder.sparkgeo.uk/) in
   one browser window.
2. Open this guide in a second window (or a second monitor) to follow along.
3. Work through the exercises at their own pace, exporting their configuration
   frequently so nothing is lost if the browser tab closes.

!!! tip "For facilitators"
    Each exercise is intentionally short (roughly 3–10 minutes) so you can pause
    between exercises for questions, and so late-joining delegates can catch up
    quickly by jumping to the current exercise.
