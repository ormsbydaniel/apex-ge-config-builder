# 4-1. Pre-requisites

Complete [2. My first config](../02-getting-started/index.md) and
[3. Working with Services](../03-working-with-services/index.md) first — this
tutorial assumes you already have both a direct WMS layer and one or more
layers added from recommended services.

!!! tip "Export often"
    Export your configuration after each step so you can recover if your
    browser tab closes.
