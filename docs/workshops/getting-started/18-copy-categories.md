# Copy categories between layers

Now that the COG layer has a full set of categories, copy them into the WMS
World Cover layer without pasting JSON.

1. Edit the *World Cover* WMS layer card from Part 2.
2. Open the **Categories** section.
3. Use **Copy from layer** to copy the categories from the *World Cover COG*
   layer.
4. Save the layer card and preview — both layers now share the same legend.
