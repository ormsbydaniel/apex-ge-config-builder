# 3. Categorical Data

Configure categories for WMS and COG layers, use the JSON editor for bulk
edits and copy categories between layers.

## Pre-requisites

Complete [1. Getting Started](../01-getting-started/index.md) and
[2. Working with Services](../02-working-with-services/index.md) first — this
exercise assumes you already have both a direct WMS layer and one or more
layers added from recommended services.

## Steps

1. [Categories — key concepts](01-categories-intro.md)
2. [Categories for a WMS layer](02-categories-wms.md)
3. [Categories for a COG](03-categories-cog.md)
4. [Use the JSON editor](04-categories-json-editor.md)
5. [Copy categories between layers](05-copy-categories.md)

!!! tip "Export often"
    Export your configuration after each step so you can recover if your
    browser tab closes.
