# 2-6. Your first layer card

A **layer card** is a UI element in the Geospatial Explorer into which we
attach content — descriptions, data sources, statistics, constraints and so on.

1. On the **Layers** tab, expand your *Forest Carbon* interface group and select **+ Add layer** followed by **Add layer card**. Leave the **default** layer type and layout style.
2. Fill in the layer details:

    - **Layer name:** `Above Ground Biomass`
    - **Description:** Paste the text below or write something similar yourself. The description supports basic Markdown, so the bold text will render correctly in the layer's info panel in the Explorer.

    ```text
    Above-ground biomass (AGB) is the **total dry mass of living vegetation** above the soil, including tree trunks, branches, bark, and leaves. It is commonly used to estimate how much carbon is stored in forests.
    ```

    - **Attribution text:** `Forest Carbon Monitoring`
    - **Attribution URL:** <https://www.forestcarbonplatform.org/>

3. Leave all other settings as default or blank, then select
   **Create layer card**.

You now have a layer card in read-only mode, ready to receive data. The card
shows the name, description and attribution you entered, plus tabs for
**Datasets**, **Statistics**, **Constraints** and **Charts**.



See [Standard layers](../../layers/standard-layers.md) for the full list of
layer options.
