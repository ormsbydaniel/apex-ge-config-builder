# 2-5. Your first layer card

A **layer card** is a UI element in the Geospatial Explorer into which we
attach content — descriptions, data sources, statistics, constraints and so on.

1. On the **Layers** tab, expand your *Forest Carbon* interface group and
   select **+ Add layer**.
2. Leave the **default** layer type and layout style.
3. Type `Above Ground Biomass` into the **Layer name** field.
4. Enter a suitable **Description** — this appears in the layer's info panel
   in the Explorer.
5. Add `Forest Carbon` as the **Attribution text**. Add an **Attribution URL**
   to a Forest Carbon website if you have one to hand.
6. Select **Create layer card**.

You now have a layer card in read-only mode, ready to receive data. The card
shows the name, description and attribution you entered, plus tabs for
**Datasets**, **Statistics**, **Constraints** and **Charts**.



See [Standard layers](../../layers/standard-layers.md) for the full list of
layer options.
