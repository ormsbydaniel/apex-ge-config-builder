# 3-1. Pre-requisites

Complete [2. My first config](../02-getting-started/index.md) first — this
tutorial assumes you already have a configuration with an interface group, a
base map and at least one layer card.

!!! tip "Export often"
    Export your configuration after each step so you can recover if your
    browser tab closes.
