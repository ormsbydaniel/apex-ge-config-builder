# 3-5. Add more WMS layers

Now that recommended services are registered, adding WMS layers from them is a
few clicks.

1. Create a new **layer card** called `temp` — we'll rename it once we've
   picked the data.
2. On the card, select **+ Add dataset** and then **From service**.
3. Browse to one of the WMS services — for example **CLMS**.
4. **Pick a WMS layer** of interest and add it to your layer card.
5. **Edit** the layer card and rename it from `temp` to something meaningful
   for the data you picked. Adjust attribution and controls as needed.

Any WMS layer you pick from a registered service is added to the layer card
just like a direct-connection layer — you only need to remember to rename the
card and set attribution afterwards.
