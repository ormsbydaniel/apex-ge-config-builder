# 7. Constraints

## Tutorial Objectives

![Constraints tutorial hero image](../../assets/screenshots/tutorial-07-hero.png)

Build a wind power density layer for Austria and filter it with categorical,
continuous and combined constraints.

By the end of this tutorial you will be able to:

- Explain what a constraint does to the rendered data.
- Build a COG layer with a colormap, units and attribution.
- Create a categorical constraint rendered as checkboxes.
- Add continuous constraints rendered as sliders.
- Group a continuous variable into named bands with a combined constraint.
- Prepare secondary constraint layers that match your primary data.
