# Workshop — FOSS4G UK 2026

## Welcome to the Geospatial Explorer workshop

The European Space Agency's [**APEx**](https://apex.esa.int/) project provides a set of tools and
services designed to help the Earth Observation (EO) community disseminate
the outputs of EO-based research and development work. One of those tools is
the **Geospatial Explorer** — an interactive web map dashboard that
practitioners can use to build their own solutions in an entirely no-code
environment.

In this workshop, delegates will use the **Geospatial Explorer Configuration
Builder** to create their own web map application. Led by Sparkgeo
(developers of the Geospatial Explorer) and accompanied by comprehensive
notes, attendees will:

- Gain a comprehensive insight into the capabilities of the Geospatial
  Explorer.
- Build their very own bespoke configuration, featuring data
  visualisations, interactive charts and graphs, time-series animations,
  data filters and constraints, interactive **storymaps** and more.
- Work with — and learn about — cloud-native geospatial data and services,
  including a fascinating array of Earth observation data and derived
  products.
- Work with — and learn about — SpatioTemporal Asset Catalogs (STAC), the
  metadata standard for EO.
- Witness on-the-fly EO algorithm execution from the APEx algorithm
  catalogue.
- Have fun.

## How the day works

The workshop is built from the [tutorials](../index.md) on this site. Everyone
works through the **core** track together, then chooses a **topic** track based
on their own interests. Nothing is thrown away at the end — the same notes are
here for you to revisit, and to pick up the topics you didn't get to.

## Before you start

- Open the [Config Builder](https://apex-ge-config-builder.sparkgeo.uk/) in one
  window and this guide in another. Two monitors are ideal; two browser tabs
  work fine.
- Any modern browser (Chrome, Firefox, Edge, Safari) will do. There is nothing
  to install.
- **Export your configuration often.** There is no cloud save.
- Interrupt the facilitator at any time — questions are welcome and usually
  help everyone. If you get stuck, flag it early rather than falling behind.

### Part 1 — Core track (everyone)

| Block | Tutorial | Approx. |

| 1 | [Familiarisation](../core/familiarisation/index.md) | 20 min |

### Part 2 — Choose your track

Pick **one** topic to work through. Delegates will be tackling different
topics at this point — that's intentional, and there is time at the end to
compare notes.

| Topic tutorial | Who it suits |
|---|---|
| [Categories for WMS and COG](../topics/categorical-data/wms-and-cog/index.md) | You work with classifications — land cover, habitat, soil type — and want clear legends |
| [Timestamps for COG and STAC](../topics/time-series/cog-timestamps/index.md) | You have a stack of dated rasters, or a STAC collection, and want an animated time slider |
| [Timestamps for WMS services](../topics/time-series/wms-timestamps/index.md) | Your time-varying data is published as a WMS / WMTS service |
| [Categorical and continuous constraints](../topics/constraints/categorical-and-continuous/index.md) | You want users to filter what's rendered — by class, by value range, or both |

### Part 3 — Wrap-up

- Share what you built: export your config and pass the JSON to a neighbour to
  load in their own browser.
- Quick round of what worked, what didn't, and what you'd like the
  Configuration Builder to do next.

!!! tip "For facilitators"
    Each step within a tutorial is intentionally short (roughly 3–10 minutes)
    so you can pause between steps for questions, and so late-joining delegates
    can catch up quickly by jumping to the current step.
