# Pre-requisites

Complete the [core track](../../index.md#core-track) first — this tutorial
assumes you already have a configuration with an interface group, a base map
and at least one layer card, plus a direct WMS layer and one or more layers
added from recommended services.

!!! tip "Export often"
    Export your configuration after each step so you can recover if your
    browser tab closes.
